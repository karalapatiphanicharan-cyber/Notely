# Notely

Notely is a minimalist, offline-first notes application designed for a distraction-free writing experience.

## Features

- **Offline-First:** Works without an internet connection using IndexedDB.
- **PWA Support:** Installable on desktop and mobile devices.
- **Privacy Mode:** Hide note content for a more secure writing environment.
- **Minimalist Design:** Clean whitespace and a premium aesthetic.
- **Search & Filter:** Find your notes instantly.
- **Theme System:** Supports light, dark, and system color schemes.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- Zustand
- Lucide React
- IndexedDB (idb)
- vite-plugin-pwa

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```
